# Content specification for the conceptual project-flow diagram

Figure 1 is a manually composed TikZ diagram, not a numerical experiment. Manuscript sources are excluded. This specification records the scientific content for independent redrawing.

1. Interval-valued multiobjective information and output budget K enter the protocol.
2. At round t, the learner outputs at most K representatives before receiving that round's feedback.
3. A single objective-value interval is queried at an output point; the adaptive construction uses the rightmost output.
4. Score the worst-target positive-part set coverage minus the world-specific optimal K-set floor.
5. The stationary hidden-translation branch uses common envelopes and indistinguishable valid responses to obtain a lower result.
6. Under the same protocol, an informative first interval permits translation estimation and shifted oracle representatives on later rounds, giving an adaptive upper result.
7. The application branch uses changing fixed Bank Marketing pools, two outputs and exact finite-pool intervals. It measures the same coverage metric outside the stationary translation minimax class.

Arrows follow steps 1–4 then split into branches 5–7. There is no input dataset, random seed or numerical output for this diagram. Exact typography depends on the private manuscript TikZ source; all computational figures are regenerated by `experiments/final_jgo_revision_analysis.py`.
