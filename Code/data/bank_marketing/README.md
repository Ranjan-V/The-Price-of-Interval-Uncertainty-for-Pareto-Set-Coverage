# JCAM EXP-10 Bank Marketing input

`bank_marketing_uci.zip` is the UCI Bank Marketing download from
https://archive.ics.uci.edu/dataset/222/bank+marketing . It contains the
date-ordered `bank-additional-full.csv` (41,188 rows). Source authors:
S. Moro, P. Rita, and P. Cortez (2014). UCI lists a CC BY 4.0 license.

`bank_stream.npz` is generated by `Code/experiments/prepare_bank_marketing.py`.
`bank_stream.metadata.json` records the exact source and derived-file hashes,
batch construction, causal feature scaling, group definition, and the
uncalibrated interval radii. The post-call `duration` field is excluded.

The evaluation is exploratory. Published row order is chronological, but
per-record timestamps are not supplied. The chosen radii are fixed sensitivity
bands, not verified population confidence intervals.
